# 🌍 NewsAtlas | Intelligence Platform

A high-performance, minimalist global intelligence dashboard designed for professional data visualization. NewsAtlas transforms complex global data streams into a clean, distraction-free terminal experience.

---

## ⚡ Core Features

- **Intel Dashboard**: AI-powered situational briefings and global news synthesis.
- **Global News Feed**: Real-time signal intelligence from 50+ trusted sources.
* **Financial Terminal**: Live market telemetry, exchange data, and commodity tracking.
- **Economic Analysis**: Macro-economic indicators and global GDP tracking.
- **Atmospheric Node**: Environmental telemetry and aeronautical weather data.
- **Orbital Map interface**: A refined dark-mode 3D globe with seamless 2D/3D projection switching.

---

## 🛠 Tech Stack

- **Frontend**: Vanilla JavaScript (ES2022+), CSS3 (Minimalist Dark System), D3.js, Mapbox GL JS.
- **Backend**: Node.js with Express.
- **AI Core**: Groq AI (Llama 3) for intelligence synthesis.
- **Database/Session**: Firebase (Anonymous authentication).
- **Typography**: Plus Jakarta Sans & JetBrains Mono.

## 🚀 Quick Start

### 1. Prerequisites
- Node.js 18+
- API keys for Mapbox and Groq Cloud.

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/abhisheksati132/news-atlas-live.git

# Install dependencies
npm install
```

### 3. Environment Setup
Create a `.env` file in the root directory:
```env
MAPBOX_TOKEN=your_mapbox_token
GROQ_API_KEY=your_groq_api_key
```

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to access the terminal.
